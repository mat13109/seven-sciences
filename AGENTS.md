# Agent Notes

## Project Type
Godot 4.6 .NET (C#) mobile app — a 7 Wonders board game science victory points calculator.

SDK: `Godot.NET.Sdk/4.6.2` via csproj, targets `net8.0`.

**Namespace mismatch:** csproj declares `<RootNamespace>SevenSciences</RootNamespace>` but all source files use `namespace SevenScience;` (no trailing 's'). This is intentional and works with the Godot SDK.

## Scoring Rules
Two cumulative scoring methods:

### Identical-symbol sets
For each symbol type, points = count². Examples: 1→1pt, 2→4pt, 3→9pt, 4→16pt.

### Sets of 3 different symbols
Each complete trio of {Compass, Tablet, Cogwheel} awards **7 points** (or **10** if the UpgradeGroup toggle is on). Points = `min(counts) * GroupValue`.

Both methods stack: identical-symbol score + trios score.

## GroupPlus power
`Maths.GroupPlusCount` (0-5, set from the GroupPlus `StackCounter` in `Main`) adds that many symbols of the type owned the most, applied after wild cards are assigned. On a tie the best tied type is used, and nothing is added when no symbol is owned. `ResetScore` clears the counter.

## Wild Card Optimization (`Maths.cs`)
- The wild counter is capped at 3 (the game's maximum), so a recursive brute-force tries every assignment and picks the max (`CalculateScienceScore`). **Must call `Maths.Reset()` first** — static state is reused across calls.

## Code Structure

```
Scripts/
  Main.cs              — root node, orchestrates UI → scoring pipeline
  Calculus/
    Maths.cs           — core scoring (no-wild + recursive wild)
    EScienceSymbol.cs  — enum: Compass, Tablet, Cogwheel, Wild, Count
    UpgradeGroup.cs    — CheckButton that toggles GroupValue between 7 and 10
    ResetScore.cs      — resets all containers to 0; finds Main via "/root/Main"
  UI/
    ScienceContainer.cs — per-symbol counter (HBoxContainer), fires OnCardCountChanged on change
    CalculatorButton.cs — label wrapper button, uses _defaultText export
  Performances/
    PerformanceTester.cs — in-engine benchmark; reads _isEnabled/_iterationCount/_wildCount exports, quits after printing average ms
Scenes/
  CalculatorInterface.tscn — only scene file
Prefabs/
  CalculatorButtonPrefab.tscn
  ScienceContainerPrefab.tscn
Art/                   — PNG sprites (.import files generated by Godot)
```

**Key wiring:**
- UI containers are discovered by `Main.FindContainers()` scanning children of the first node.
- `ScienceContainer.ScienceCount` setter fires `Main.OnCardCountChanged` event, triggering recalculation.
- `ResetScore` accesses Main via `/root/Main` (Godot root path), not scene tree traversal.

## Code Style
- `.editorconfig`: 4-space indent for C#, UTF-8-BOM, file-scoped namespaces, trailing newline.
- Private fields: `_camelCase`. Static fields: `s_camelCase` (with `static` modifier). Constant fields: `PascalCase`.
- Expression-bodied members encouraged (`= true:suggestion`). `var` discouraged except when type is obvious.
- Using directives outside namespace. No qualification for `this`/`base` members.

## Testing / Verification
**No test framework.** The only verification is `PerformanceTester.cs`, which runs in-engine: export it as a scene, set `_isEnabled=true` and configure iteration/wild count via the Godot editor, then run — it prints average ms to console and quits.

Run in Godot editor with F5 (default). No CLI build/test commands needed for development; `godot --editor` handles everything.

## Gotchas
- `Maths.s_resultsTemp` is static — call `Maths.Reset()` before recursive wild-card calculation.
- `ResetScore.Reset()` toggles the upgrade group button via `ToggleMode = false; ToggleMode = true;` rather than calling `Button.Pressed`.
